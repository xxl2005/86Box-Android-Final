# 86Box Android v0.6.0 – Hardware-Konfigurator

Neu:
- visueller Hardware-Konfigurator pro VM-Profil
- Mainboard/Maschine
- RAM
- Grafik
- Sound
- Netzwerk + SLiRP
- Maus
- Storage-Controller
- Dynarec
- Zeitsynchronisation
- Save & Start
- offizielles 86Box-App-Icon

Der Editor arbeitet zeilenbasiert auf `86box.cfg` und erhält unbekannte bzw. gerätespezifische Abschnitte. Vorhandene CPU-Einstellungen werden angezeigt und standardmäßig erhalten. Optional kann der Benutzer sie auf eine automatisch zum Mainboard kompatible CPU zurücksetzen. Bei neuen Profilen verwendet 86Box automatisch eine passende CPU.

Hinweis: Für das gewählte Mainboard werden weiterhin die entsprechenden originalen 86Box-ROM-/BIOS-Dateien benötigt.

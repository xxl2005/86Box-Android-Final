# 86Box Android v0.9.29 – Game-Key-Overlay Transparenz

## Neu

- GAME KEY OVERLAY besitzt **KEY BACKGROUND OPACITY** von 0–100 %.
- Standard bleibt 100 %, damit bestehende Installationen optisch unverändert starten.
- 0 % macht nur den Tastenhintergrund transparent; die Tastenbeschriftung bleibt voll sichtbar.
- Ein dünner Rand bleibt auch bei 0 % sichtbar, damit die Taste auffindbar bleibt.
- Eingestellte HOLD-Tasten zeigen ihren eingerasteten Zustand zusätzlich mit türkisfarbener Beschriftung.
- Transparenz gilt global für alle Game-Key-Overlay-Tasten und wird gespeichert.

## Unverändert

- HOLD/TAB-Latch
- MOVE MODE und gespeicherte Positionen
- Touch-Maus parallel zu gehaltenen Overlay-Tasten
- Virtuelle Volltastatur und Scaler
- True Auto / ADPF / Thread Assist v2

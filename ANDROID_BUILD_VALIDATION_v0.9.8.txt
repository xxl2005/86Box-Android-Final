v0.9.8 changes
--------------
1. Stable Spinner selection guard prevents unchanged delayed startup callbacks from cascading and resetting CPU frequency.
2. Responsive dp scaling for VM overlay, Profile Manager and Hardware Configurator.
3. Whole Profile Manager scrolls on short displays; compact action rows stack vertically.
4. Hardware Configurator bottom buttons stack vertically on compact displays.
5. Touch/input settings and VM display dialog are scrollable.
6. VM toolbar is vertically scrollable with a persistent scrollbar.
7. New VIEW dialog: Stretch / 4:3 / Auto Fit / Integer / Integer 4:3 and image size 50-300%.
8. Android renderer scale mode is passed to native SDL renderer; <100% centers a smaller image, >100% zooms/pans.
9. Physical mouse requests pointer capture on hover/move/click over the VM, prefers relative axes, and has vendor fallbacks.
10. Physical mouse logging covers Android events/capture/deltas plus native move/button/wheel events and mouse_ready state.

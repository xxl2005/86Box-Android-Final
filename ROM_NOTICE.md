# ROM and BIOS files / ROM- und BIOS-Dateien

## English

This source repository and the v0.11.1 Preview APK contain **no 86Box ROM or BIOS set**. The placeholder at `android/app/src/main/assets/86box/roms/` is not a ROM.

Obtain ROM/BIOS files separately and use them only where you have the necessary rights. The [86Box ROM project](https://github.com/86Box/roms) is a reference for the expected layout; check the rights and notices that apply to each file before distributing it.

For a source build, place your permitted ROM files under `android/app/src/main/assets/86box/roms/` before building. The Android app also offers **IMPORT ROM ZIP** to load a compatible ROM archive into its private ROM library after installation. ROM availability determines which emulated machines can start.

## Deutsch

Dieses Quell-Repository und die v0.11.1-Preview-APK enthalten **keinen 86Box-ROM- oder BIOS-Satz**. Die Platzhalterdatei unter `android/app/src/main/assets/86box/roms/` ist kein ROM.

ROM-/BIOS-Dateien müssen getrennt beschafft werden. Verwende sie nur, wenn du die nötigen Rechte hast. Das [86Box-ROM-Projekt](https://github.com/86Box/roms) zeigt die erwartete Verzeichnisstruktur; prüfe vor einer Weitergabe die Rechte und Hinweise zu jeder Datei.

Für einen Quell-Build erlaubte ROM-Dateien vor dem Bau unter `android/app/src/main/assets/86box/roms/` ablegen. Nach der Installation kann die App über **IMPORT ROM ZIP** ein kompatibles ROM-Archiv in ihre private ROM-Bibliothek importieren. Welche emulierten Maschinen starten können, hängt von den vorhandenen ROMs ab.

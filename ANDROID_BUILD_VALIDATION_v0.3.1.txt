NATIVE THREADING MODEL
======================
Java UI/input callbacks do not directly mutate the emulated keyboard/mouse state.
The JNI bridge pushes SDL user events; 86Box processes the hardware key/mouse actions
on the emulator SDL event thread. Mouse state updates retain the existing mouse mutex.

ANDROID POINTER CAPTURE API CHECK
=================================
The implementation uses View.setOnCapturedPointerListener + requestPointerCapture().
For SOURCE_MOUSE_RELATIVE events, getX()/getY() are treated as relative deltas.
The project minSdk remains 28; pointer capture was introduced in Android API 26.

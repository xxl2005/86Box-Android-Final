# 86Box Android v0.9.27 – Virtual Keyboard Screen Fit + Scaler

- Virtuelle PC-Tastatur passt jede Tastenreihe automatisch an die verfügbare Bildschirmbreite an.
- Kein horizontales Scrollen der Tastenreihen mehr notwendig.
- Auto-Fit berücksichtigt Bildschirmbreite und -höhe.
- Manueller Größenfaktor 50–140 % über − / Prozent / + direkt in der Tastatur.
- Tipp auf den Prozentwert setzt auf 100 % zurück.
- Skalierung wird persistent gespeichert (`virtual_keyboard_scale_percent`).
- Tastaturcontainer verwendet 78 % der Bildschirmhöhe und nahezu die volle Breite.
- Bei Android-Konfigurations-/Auflösungsänderungen wird die Tastatur neu angepasst.
- Direkter XT-Scancode-Pfad, Modifier-Verhalten und Game-Key-Overlay unverändert.

Version: 0.9.27 / versionCode 62.

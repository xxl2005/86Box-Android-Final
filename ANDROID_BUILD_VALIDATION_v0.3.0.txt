LIMITATION / NOT CLAIMED
========================
The execution environment used for this validation has no Android SDK/NDK installed:
  ANDROID_HOME     = unset
  ANDROID_SDK_ROOT = unset
  sdkmanager       = unavailable
  adb              = unavailable

Therefore a real Gradle + Android NDK compile of the final APK and a device/runtime test
could NOT be performed here. The supplied Windows BUILD_APK.bat is intended to install/use
Android API 35, Build Tools 35.0.0 and NDK 28.2.13676358 (r28c) and then build both ABIs.

A successful structural/static validation is not a substitute for the first real device build.
If the Windows build reports an NDK/link/runtime error, retain the complete console log; it can
be used for the next port-fix iteration.
